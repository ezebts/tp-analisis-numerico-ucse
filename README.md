
## UCSE: Análisis Numérico

**Backend**

- Python 3.14

**Frontend**

- [Tailwindcss](https://github.com/tailwindlabs/tailwindcss/releases/)
*(Instalar en `.tools/tailwindcss`)*

**DevTools**

- `make` (build)
- Herramientas en `.tools/`

**Local**
`make dev`   *(Inicia la app en http://127.0.0.1:8000)*
`make tests` *(Corre los tests del proyecto)*
